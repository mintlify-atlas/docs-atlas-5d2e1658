## What is a code step?

A code step lets you run arbitrary code as part of a workflow. Use code steps when a pre-built action doesn’t cover your use case — to transform data, call any API, implement business logic, or do anything a pre-built component can’t.

## What you can do in a code step

- **Import any package** — declare the import at the top of the file and Pipedream downloads the dependency automatically. No `package.json` or build step required.
- **Access upstream step data** — read output from any previous step via the `steps` variable.
- **Connect to Pipedream apps** — add an app prop to use your connected accounts (OAuth tokens, API keys) directly in code.
- **Export data** — `return` a value to make it available to downstream steps.
- **End a workflow early** — call `$.flow.exit()` to stop execution with an optional message.

## Accessing step data

In each language, you can read data from upstream steps:

<Tabs>
  <Tab title="Node.js">
    ```javascript
    export default defineComponent({
      async run({ steps, $ }) {
        const body = steps.trigger.event.body;
        const prevResult = steps.step_1.$return_value;
        return body;
      },
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    def handler(pd: "pipedream"):
        body = pd.steps["trigger"]["event"]["body"]
        prev_result = pd.steps["step_1"]["$return_value"]
        return body
    ```
  </Tab>
  <Tab title="Go">
    ```go
    import pd "github.com/PipedreamHQ/pipedream-go"

    func main() {
        body := pd.Steps["trigger"].(map[string]interface{})["event"]
        pd.Respond(body)
    }
    ```
  </Tab>
  <Tab title="Bash">
    ```bash
    # Step data is available as environment variables
    echo $PIPEDREAM_STEPS
    ```
  </Tab>
</Tabs>

## Connecting to apps

In Node.js steps, add an app prop to access credentials for any connected Pipedream account:

```javascript
import { WebClient } from "@slack/web-api";

export default defineComponent({
  props: {
    slack: {
      type: "app",
      app: "slack",
    },
  },
  async run({ steps, $ }) {
    const web = new WebClient(this.slack.$auth.oauth_access_token);
    return await web.chat.postMessage({
      text: "Hello from Pipedream!",
      channel: "#general",
    });
  },
});
```
