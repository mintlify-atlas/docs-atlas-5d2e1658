## What is Pipedream?

Pipedream is an integration platform for developers. It provides a free, hosted platform for connecting apps and developing event-driven automations. With over 1,000 fully-integrated applications, you can use pre-built components to send messages to Slack, add rows to Google Sheets, and much more — or run any Node.js, Python, Golang, or Bash code when you need custom logic.

## Why Pipedream?

**Built for developers.** Pipedream is low-code in the best way: use pre-built components when performing common actions, write custom code when you need full control.

**1,000+ integrations out of the box.** Connect to popular services like Slack, GitHub, Google Sheets, Stripe, HubSpot, and hundreds more — all with built-in OAuth and credential management.

**Multi-language code steps.** Unlike other automation tools, Pipedream lets you run real Node.js, Python, Go, or Bash code. Import any npm package, PyPI package, or Go module directly in your step.

**Free for individuals.** Pipedream offers a generous free tier. No credit card required to get started.

**SOC 2 compliant.** Pipedream has demonstrated SOC 2 compliance and can provide a SOC 2 Type 2 report upon request.

## Get started

<Steps>
  <Step title="Create an account">
    Sign up for free at [pipedream.com](https://pipedream.com/auth/signup). No credit card required.
  </Step>
  <Step title="Build your first workflow">
    Follow the [quickstart guide](/quickstart) to build a workflow that responds to an HTTP request or a schedule.
  </Step>
  <Step title="Connect an app">
    Browse [integrations](/integrations/apps) and connect an app you use to trigger events or run actions.
  </Step>
  <Step title="Add custom logic">
    Add a [code step](/code/overview) to transform data, call APIs, or implement business logic in the language of your choice.
  </Step>
</Steps>
