---
title: "Sources"
description: "REST API endpoints for managing deployed event sources."
---

Event sources watch for new data from external services and emit events to trigger workflows. Use these endpoints to deploy, inspect, and delete sources, and to retrieve their emitted events.

## List sources

```
GET /v1/sources
```

Returns a list of deployed sources in your account.

### Request

```bash
curl https://api.pipedream.com/v1/sources \
  -H "Authorization: Bearer <api_key>"
```

### Query parameters

<ParamField query="limit" type="integer">
  Maximum number of sources to return. Defaults to 10.
</ParamField>

<ParamField query="after" type="string">
  Pagination cursor. Pass the `end_cursor` from a previous response.
</ParamField>

### Response

```json
{
  "data": [
    {
      "id": "dc_abc123",
      "component_id": "github-new-commit",
      "name": "New Commit (my-repo)",
      "active": true,
      "created_at": "2024-01-15T10:30:00.000Z"
    }
  ],
  "page_info": {
    "total_count": 5,
    "count": 5,
    "start_cursor": "dc_abc123",
    "end_cursor": "dc_xyz789"
  }
}
```

## Deploy a source

```
POST /v1/sources
```

Deploys a new event source from a component.

### Request

```bash
curl -X POST https://api.pipedream.com/v1/sources \
  -H "Authorization: Bearer <api_key>" \
  -H "Content-Type: application/json" \
  -d '{
    "component_id": "github-new-commit",
    "name": "New Commit on main",
    "props": {
      "github": { "authProvisionId": "apn_abc123" },
      "owner": "PipedreamHQ",
      "repo": "pipedream",
      "branch": "main"
    }
  }'
```

### Request body

<ParamField body="component_id" type="string" required>
  The component key to deploy (for example, `github-new-commit`).
</ParamField>

<ParamField body="name" type="string">
  A human-readable name for the deployed source instance.
</ParamField>

<ParamField body="props" type="object">
  Configuration props for the component. Keys match the component's prop names. App connections are specified as `{ "authProvisionId": "apn_..." }`.
</ParamField>

### Response

```json
{
  "data": {
    "id": "dc_newone",
    "component_id": "github-new-commit",
    "name": "New Commit on main",
    "active": true,
    "created_at": "2024-03-15T12:00:00.000Z"
  }
}
```

## Get a source

```
GET /v1/sources/{source_id}
```

Returns the details of a deployed source.

### Request

```bash
curl https://api.pipedream.com/v1/sources/dc_abc123 \
  -H "Authorization: Bearer <api_key>"
```

### Path parameters

<ParamField path="source_id" type="string" required>
  The source ID. Prefixed with `dc_`.
</ParamField>

### Response

```json
{
  "data": {
    "id": "dc_abc123",
    "component_id": "github-new-commit",
    "name": "New Commit on main",
    "active": true,
    "created_at": "2024-01-15T10:30:00.000Z"
  }
}
```

## Delete a source

```
DELETE /v1/sources/{source_id}
```

Deletes a deployed source. This also stops any workflows triggered by this source.

### Request

```bash
curl -X DELETE https://api.pipedream.com/v1/sources/dc_abc123 \
  -H "Authorization: Bearer <api_key>"
```

### Path parameters

<ParamField path="source_id" type="string" required>
  The source ID to delete.
</ParamField>

### Response

Returns `200 OK` with no body on success.

## Get events from a source

```
GET /v1/sources/{source_id}/events
```

Returns the most recent events emitted by a source.

### Request

```bash
curl "https://api.pipedream.com/v1/sources/dc_abc123/events?limit=5" \
  -H "Authorization: Bearer <api_key>"
```

### Path parameters

<ParamField path="source_id" type="string" required>
  The source ID.
</ParamField>

### Query parameters

<ParamField query="limit" type="integer">
  Number of events to return. Defaults to 10.
</ParamField>

<ParamField query="before" type="string">
  Return events before this event ID.
</ParamField>

<ParamField query="after" type="string">
  Return events after this event ID.
</ParamField>

### Response

```json
{
  "data": [
    {
      "id": "evt_abc123",
      "indexed_at_ms": 1710504000000,
      "event": {
        "sha": "a1b2c3d",
        "commit": {
          "message": "Fix bug in login flow",
          "author": { "name": "Jane Doe" }
        }
      }
    }
  ]
}
```

<ResponseField name="data[].id" type="string">
  The event ID.
</ResponseField>

<ResponseField name="data[].indexed_at_ms" type="integer">
  Unix timestamp in milliseconds when the event was indexed.
</ResponseField>

<ResponseField name="data[].event" type="object">
  The event payload as emitted by the source.
</ResponseField>
