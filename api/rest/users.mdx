---
title: "Users"
description: "REST API endpoints for retrieving your Pipedream user account information."
---

Use the users endpoint to retrieve information about your Pipedream account. This is also useful for verifying that your API key is valid.

## Get current user

```
GET /v1/users/me
```

Returns information about the authenticated user.

### Request

```bash
curl https://api.pipedream.com/v1/users/me \
  -H "Authorization: Bearer <api_key>"
```

### Response

```json
{
  "data": {
    "id": "u_abc123",
    "username": "jane-doe",
    "email": "jane@example.com",
    "name": "Jane Doe",
    "created_at": "2022-06-01T00:00:00.000Z"
  }
}
```

<ResponseField name="data.id" type="string">
  Unique user ID, prefixed with `u_`.
</ResponseField>

<ResponseField name="data.username" type="string">
  The user's Pipedream username.
</ResponseField>

<ResponseField name="data.email" type="string">
  The email address associated with the account.
</ResponseField>

<ResponseField name="data.name" type="string">
  The user's display name.
</ResponseField>

<ResponseField name="data.created_at" type="string">
  ISO 8601 timestamp when the account was created.
</ResponseField>

### Use cases

- **Verify authentication**: Make a request to `/v1/users/me` to confirm your API key is valid before making other requests.
- **Get your user ID**: Use the returned `id` to identify your account in logs or other systems.
