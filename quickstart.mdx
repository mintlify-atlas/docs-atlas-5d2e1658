title: "Quickstart"
description: "Build your first workflow in minutes — trigger it with an HTTP request and process data with a Node.js code step."
---

In this guide you'll create a workflow that accepts an HTTP request, processes the payload with a Node.js code step, and returns a response.

<Steps>
  <Step title="Create an account">
    Go to [pipedream.com](https://pipedream.com/auth/signup) and sign up for free. No credit card required.
  </Step>

  <Step title="Create a new workflow">
    From the [Pipedream dashboard](https://pipedream.com), click **+ New Workflow**. Give your workflow a name, then click **Create**.
  </Step>

  <Step title="Add an HTTP trigger">
    On the trigger step, click **Select a trigger** and choose **HTTP / Webhook**. Then select **New Requests**.

    Pipedream immediately provisions a unique URL for your workflow — something like `https://eo1a2b3c4d.m.pipedream.net`. Copy this URL; you'll use it to send test requests.

    <Tip>The trigger URL is ready as soon as you select the HTTP trigger — no deploy step is required to start testing.</Tip>
  </Step>

  <Step title="Add a Node.js code step">
    Click **+** below the trigger to add a new step. Choose **Run custom code** and select **Node.js**.

    Pipedream opens an in-browser code editor pre-populated with a default export. Replace the contents with the following:

    ```javascript
    export default defineComponent({
      async run({ steps, $ }) {
        const body = steps.trigger.event.body;

        // Transform or validate the incoming payload
        const response = {
          message: `Received ${Object.keys(body).length} field(s)`,
          data: body,
          ts: new Date().toISOString(),
        };

        return response;
      },
    });
    ```

    This step reads the request body from `steps.trigger.event.body`, builds a response object, and returns it. The return value is available to all downstream steps as `steps.<step_name>.$return_value`.
  </Step>

  <Step title="Test the workflow">
    Click **Test** at the top of the trigger step to send a sample request, or send a real HTTP request from your terminal:

    ```bash
    curl -X POST https://your-endpoint.m.pipedream.net \
      -H "Content-Type: application/json" \
      -d '{"name": "Alice", "action": "signup"}'
    ```

    Pipedream runs each step and displays the result inline. Expand the code step to inspect its return value:

    ```json
    {
      "message": "Received 2 field(s)",
      "data": { "name": "Alice", "action": "signup" },
      "ts": "2024-04-10T15:30:00.000Z"
    }
    ```

    <Note>Each test run is isolated. Results appear in the **Inspector** panel on the right so you can step through the execution.</Note>
  </Step>

  <Step title="Deploy the workflow">
    When you're satisfied with the results, click **Deploy** in the top-right corner. Your workflow is now live and will process every incoming request automatically.

    Pipedream runs your workflow on managed infrastructure — there are no servers to provision, containers to build, or scaling decisions to make.
  </Step>
</Steps>

## What you built

You created a workflow with two steps:

| Step | Type | What it does |
|------|------|--------------|
| `trigger` | HTTP / Webhook | Exposes a unique URL and emits each request as an event |
| `steps.code` | Node.js code step | Reads the request body and returns a transformed response |
