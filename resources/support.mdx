There are several ways to get help with Pipedream. Choose the channel that best fits your situation.

<CardGroup cols={2}>
  <Card title="Community forum" icon="users" href="https://pipedream.com/community">
    Ask questions, share workflows, and get help from the Pipedream team and community. The best place to start for most questions.
  </Card>
  <Card title="Slack" icon="slack" href="https://pipedream.com/support">
    Join the Pipedream Slack for real-time conversation with the team and other developers.
  </Card>
  <Card title="GitHub Issues" icon="github" href="https://github.com/PipedreamHQ/pipedream/issues">
    Report bugs or search for known issues. Use the [issue templates](https://github.com/PipedreamHQ/pipedream/issues/new/choose) when filing a new issue.
  </Card>
  <Card title="Email support" icon="envelope" href="mailto:support@pipedream.com">
    Email [support@pipedream.com](mailto:support@pipedream.com) for account-related questions or issues that need direct attention.
  </Card>
  <Card title="Twitter" icon="twitter" href="https://twitter.com/pipedream">
    Follow [@pipedream](https://twitter.com/pipedream) for announcements, tips, and platform updates.
  </Card>
  <Card title="Stack Overflow" icon="stack-overflow" href="https://stackoverflow.com/questions/tagged/pipedream">
    Search or ask questions tagged `pipedream` on Stack Overflow for community-sourced answers.
  </Card>
</CardGroup>

## Documentation

This documentation site covers the full Pipedream platform. If you can't find what you're looking for, try the search bar at the top of the page.

<Tip>
  Before filing a bug report, check the [existing GitHub issues](https://github.com/PipedreamHQ/pipedream/issues) to see if someone has already reported the same problem. Adding a reaction or comment to an existing issue helps the team prioritize it.
</Tip>

## Security issues

Do not report security vulnerabilities through public GitHub issues. Email [security@pipedream.com](mailto:security@pipedream.com) instead. See the [Security page](/resources/security) for details.
