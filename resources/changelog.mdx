## February 2026

- Added 40+ new app integrations, including expanded support for AI and LLM APIs
- Improved cold start performance for Node.js and Python workflow steps
- Connect SDK: added `getAccount` method for retrieving connected account details server-side
- Fixed an issue where timer-based sources could skip an interval after a platform update
- Updated component guidelines with new prop validation requirements

## January 2026

- Launched **Pipedream Connect MCP Server** for self-hosted deployments
- Node.js runtime updated to support latest LTS release
- New `$checkpoint` API for persisting state across workflow executions
- Added support for Go 1.22 in Golang code steps
- Expanded event retention for paid plans
- Performance improvements to the workflow editor

## December 2025

- Released Pipedream Connect browser SDK with React component library
- Added token-based authentication flow for embedded Connect use cases
- New pre-built actions for Notion, Linear, and Anthropic Claude
- Improved error messages for OAuth connection failures
- Spellcheck CI check added to component contribution PRs

## November 2025

- Open-sourced 500+ additional pre-built components on GitHub
- Added Python 3.12 support for Python code steps
- New destination: SSE (Server-Sent Events) for real-time event streaming
- Workflow concurrency controls now configurable per-workflow
- Gitpod workspace updated for faster component development setup
