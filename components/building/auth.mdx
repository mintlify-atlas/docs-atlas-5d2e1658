---
title: "Authentication in components"
description: "Learn how to connect third-party accounts and access credentials in your components."
---

Pipedream manages authentication for over 1,000 apps. When you add an app prop to your component, Pipedream handles the OAuth flow or API key collection and passes the credentials to your component at runtime.

## Connecting an app

Add a prop with `type: "app"` and set `app` to the app's name slug:

```javascript
export default {
  name: "My Action",
  key: "my-app-my-action",
  version: "0.1.0",
  type: "action",
  props: {
    slack: {
      type: "app",
      app: "slack",
    },
  },
  async run({ steps, $ }) {
    // Access credentials via this.slack.$auth
    console.log(this.slack.$auth.oauth_access_token);
  },
};
```

When a user adds this component to their workflow, Pipedream prompts them to connect their Slack account. The connected account's credentials are then available via `this.slack.$auth`.

## Accessing OAuth tokens

For OAuth apps, access the access token via `$auth.oauth_access_token`:

```javascript
async run({ steps, $ }) {
  const response = await fetch("https://slack.com/api/conversations.list", {
    headers: {
      Authorization: `Bearer ${this.slack.$auth.oauth_access_token}`,
    },
  });
  return response.json();
},
```

Some apps use different token field names. The exact field names depend on what the app returns in its OAuth response. Common patterns include:

```javascript
this.github.$auth.oauth_access_token  // GitHub
this.google.$auth.oauth_access_token  // Google apps
this.twitter.$auth.oauth_access_token // Twitter
```

<Tip>
To see all available `$auth` fields for an app, add a `console.log(this.app_name.$auth)` in your component and check the workflow logs after a test run.
</Tip>

## Accessing API keys

For apps that authenticate with API keys, access the key via the field name configured in the app's auth settings:

```javascript
export default {
  name: "Search Issues",
  key: "linear-search-issues",
  version: "0.1.0",
  type: "action",
  props: {
    linear: {
      type: "app",
      app: "linear",
    },
  },
  async run({ steps, $ }) {
    const response = await fetch("https://api.linear.app/graphql", {
      method: "POST",
      headers: {
        Authorization: this.linear.$auth.api_key,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({ query: "{ viewer { id name } }" }),
    });
    return response.json();
  },
};
```

Common API key field names:

```javascript
this.app.$auth.api_key
this.app.$auth.token
this.app.$auth.access_token
```

## Automatic credential refresh

Pipedream automatically refreshes OAuth tokens before they expire. You never need to handle token refresh in your component code — every time `run()` executes, `this.app.$auth.oauth_access_token` contains a valid, unexpired token.

If a token cannot be refreshed (for example, the user revoked access), Pipedream marks the connected account as unhealthy and notifies the user.

## Multiple connected accounts

You can include multiple app props in a single component. Each must have a unique prop name:

```javascript
export default {
  name: "Sync GitHub Issue to Linear",
  key: "my-app-sync-issue",
  version: "0.1.0",
  type: "action",
  props: {
    github: {
      type: "app",
      app: "github",
    },
    linear: {
      type: "app",
      app: "linear",
    },
    repoFullname: {
      type: "string",
      label: "GitHub repository",
      description: "Format: owner/repo",
    },
    issueNumber: {
      type: "integer",
      label: "Issue number",
    },
  },
  async run({ steps, $ }) {
    // Fetch from GitHub
    const response = await fetch(
      `https://api.github.com/repos/${this.repoFullname}/issues/${this.issueNumber}`,
      {
        headers: {
          Authorization: `Bearer ${this.github.$auth.oauth_access_token}`,
        },
      }
    );
    const issue = await response.json();

    // Create in Linear
    const linearResponse = await fetch("https://api.linear.app/graphql", {
      method: "POST",
      headers: {
        Authorization: this.linear.$auth.api_key,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        query: `mutation {
          issueCreate(input: { title: "${issue.title}" }) {
            issue { id title }
          }
        }`,
      }),
    });
    return linearResponse.json();
  },
};
```

## Custom OAuth apps

Pipedream uses its own OAuth app credentials by default. To use your own OAuth client ID and secret — for example, to display your brand in the OAuth consent screen — configure a custom OAuth app in **Settings > OAuth Clients** in the Pipedream dashboard.

Once configured, users who connect the app through your project use your OAuth credentials.
