title: "Props reference"
description: "Complete reference for all prop types available in Pipedream components."
---

Props define the configuration inputs for a component. Each prop appears as a field in the workflow editor where users supply values. Access prop values at runtime via `this.propName`.

## Prop fields

Every prop can include these common fields:

<ParamField path="type" type="string" required>
  The prop type. Determines the UI control and validation. See the full list of types below.
</ParamField>

<ParamField path="label" type="string">
  Human-readable label shown in the UI. Defaults to the prop key formatted as title case.
</ParamField>

<ParamField path="description" type="string">
  Markdown-formatted description shown below the input field. Use this to explain what the prop does and provide examples.
</ParamField>

<ParamField path="optional" type="boolean">
  When `true`, the prop is not required. Defaults to `false`.
</ParamField>

<ParamField path="default" type="any">
  Default value to pre-fill when the component is added to a workflow.
</ParamField>

<ParamField path="options" type="array">
  An array of values or `{ label, value }` objects to present as a dropdown. Can also be an `async options()` method.
</ParamField>

## Scalar types

### `string`

A text input field.

```javascript
props: {
  message: {
    type: "string",
    label: "Message",
    description: "The message text to send.",
    default: "Hello, world!",
  },
},
```

### `integer`

A numeric input that accepts whole numbers.

```javascript
props: {
  limit: {
    type: "integer",
    label: "Result limit",
    description: "Maximum number of results to return.",
    default: 10,
    optional: true,
  },
},
```

### `boolean`

A toggle switch for true/false values.

```javascript
props: {
  includeArchived: {
    type: "boolean",
    label: "Include archived",
    description: "When enabled, results include archived records.",
    default: false,
    optional: true,
  },
},
```

### `object`

A JSON object input.

```javascript
props: {
  metadata: {
    type: "object",
    label: "Metadata",
    description: "Key-value pairs to attach to the record.",
    optional: true,
  },
},
```

### `array`

An array input. Users can add multiple items.

```javascript
props: {
  tags: {
    type: "string[]",  // Array of strings
    label: "Tags",
    optional: true,
  },
  ids: {
    type: "integer[]", // Array of integers
    label: "IDs",
    optional: true,
  },
},
```

## Dropdown options

### Static options

Pass an array of strings or `{ label, value }` objects:

```javascript
props: {
  status: {
    type: "string",
    label: "Status",
    options: ["open", "closed", "pending"],
  },
  priority: {
    type: "string",
    label: "Priority",
    options: [
      { label: "Low", value: "1" },
      { label: "Medium", value: "2" },
      { label: "High", value: "3" },
    ],
  },
},
```

### Dynamic options

Fetch options from an API at runtime with an `async options()` method. The method receives the currently configured props as its argument:

```javascript
props: {
  github: {
    type: "app",
    app: "github",
  },
  repo: {
    type: "string",
    label: "Repository",
    description: "The repository to watch.",
    async options() {
      const response = await fetch("https://api.github.com/user/repos", {
        headers: {
          Authorization: `Bearer ${this.github.$auth.oauth_access_token}`,
        },
      });
      const repos = await response.json();
      return repos.map((r) => ({
        label: r.full_name,
        value: r.full_name,
      }));
    },
  },
},
```

## App props

Connect a user's third-party account by defining an app prop with `type: "app"`:

```javascript
props: {
  slack: {
    type: "app",
    app: "slack", // The app's name slug
  },
},
```

Pipedream presents a connect button in the UI. After connecting, access credentials via `this.app_name.$auth`. See [authentication](/components/building/auth) for details.

## Special interface props

### `$.interface.http`

Exposes a unique HTTP endpoint. Only available in sources.

```javascript
props: {
  http: {
    type: "$.interface.http",
    customResponse: true, // Optional: send a custom HTTP response from run()
  },
},
```

The `run()` method receives the incoming HTTP request as its argument.

### `$.interface.timer`

Runs the source on a schedule. Only available in sources.

```javascript
props: {
  timer: {
    type: "$.interface.timer",
    default: {
      intervalSeconds: 900, // Run every 15 minutes
    },
  },
},
```

Use a cron expression for more precise scheduling:

```javascript
timer: {
  type: "$.interface.timer",
  default: {
    cron: "0 9 * * 1-5", // 9 AM Monday–Friday
  },
},
```

### `$.service.db`

A persistent key-value store scoped to a source instance. Survives across runs.

```javascript
props: {
  db: "$.service.db",
},
```

Use `this.db.get(key)` and `this.db.set(key, value)` to read and write data:

```javascript
async run() {
  const lastRunAt = this.db.get("lastRunAt");
  // ... process new items ...
  this.db.set("lastRunAt", Date.now());
},
```

## Optional props

Set `optional: true` on any prop to make it not required:

```javascript
props: {
  subject: {
    type: "string",
    label: "Email subject",
  },
  replyTo: {
    type: "string",
    label: "Reply-to address",
    optional: true,
  },
},
```

Check whether an optional prop was provided before using it:

```javascript
async run({ steps, $ }) {
  const options = {};
  if (this.replyTo) {
    options.reply_to = this.replyTo;
  }
},
```
