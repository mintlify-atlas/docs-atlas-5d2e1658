The Pipedream SDK is a TypeScript-first package that works in both Node.js server environments and the browser. Install it once and import from the appropriate entry point for your environment.

## Prerequisites

- Node.js 18 or later
- A Pipedream account with a project and OAuth client credentials

## Install the package

<Tabs>
  <Tab title="npm">
    ```bash
    npm install @pipedream/sdk
    ```
  </Tab>
  <Tab title="yarn">
    ```bash
    yarn add @pipedream/sdk
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add @pipedream/sdk
    ```
  </Tab>
</Tabs>

## Import the client

The SDK exposes two separate entry points — one for server-side code and one for the browser. Always use the correct entry point for your environment.

### Server (Node.js)

Use the `/server` entry point in any Node.js server environment (Express, Next.js API routes, serverless functions, etc.).

<Tabs>
  <Tab title="ES Modules">
    ```typescript
    import { createBackendClient } from "@pipedream/sdk/server";
    ```
  </Tab>
  <Tab title="CommonJS">
    ```javascript
    const { createBackendClient } = require("@pipedream/sdk/server");
    ```
  </Tab>
</Tabs>

### Browser

Use the `/browser` entry point (or the root import) in client-side code.

<Tabs>
  <Tab title="ES Modules">
    ```typescript
    import { createFrontendClient } from "@pipedream/sdk/browser";
    ```
  </Tab>
  <Tab title="CommonJS">
    ```javascript
    const { createFrontendClient } = require("@pipedream/sdk");
    ```
  </Tab>
</Tabs>

<Warning>
  Never import `@pipedream/sdk/server` in browser code. The server entry point contains your OAuth credentials and must only run in a trusted server environment.
</Warning>
